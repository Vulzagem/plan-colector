# Plan Colector MLBB

Planificador del método ahorrador para sacar una skin Collector o Lucky Box
en Mobile Legends sin gastar de más.

Elegís qué skin querés, las fechas del evento y cuántos cristales de aurora
tenés guardados. La página arma el plan día por día, te dice qué hacer hoy y
calcula si vas a llegar al último día con cristales suficientes.

Todo el progreso se guarda en el navegador de cada persona: no hay servidor,
no hay cuentas, no se comparte nada.

**Abrir:** https://vulzagem.github.io/plan-colector/
